== Conventions

In the steps, *Component (Tab)* names a component and the tab it lives on; you can always double-click the canvas and type its name instead. "Wire *A → B*" means drag from output A to input B. Slider settings are written as _Name: value (minimum – maximum)_ and set in the slider editor (double-click the slider's name). "Set value" means choosing menu:Set value…[] from the input grip's right-click menu.
